# Kaggle Data Visualization Course

This repository contains notebooks and hands-on exercises completed during the **Kaggle Data Visualization** course. It showcases practical data analysis and visualization techniques implemented in Python.

## 🛠️ Built With & Libraries Used
* **Python**
* **Pandas** (for data manipulation)
* **Seaborn** (for statistical data visualization)
* **Matplotlib** (for plotting and custom styling)

## 📁 Repository Contents
The repository includes exercises covering:
* Line Charts & Trends
* Bar Charts and Heatmaps
* Scatter Plots
* Distributions (Histograms, KDE plots)
* Choosing Plot Types and Custom Styles
